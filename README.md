# GUDD — памятка администратора

Бот [@Gudd_centr_nedvizhimosti_bot](https://t.me/Gudd_centr_nedvizhimosti_bot) показывает посетителям каталог недвижимости. Карточками можно управлять прямо в личном чате с ботом.

## Открыть админку

Отправьте боту команду **/admin**. Доступ есть только у назначенных администраторов. Если бот отвечает «Нет доступа», отправьте ему **/id** и передайте полученный номер техническому ответственному для добавления в список администраторов.

## Добавить объект

1. Откройте **/admin → ➕ Добавить объект**.
2. По запросам бота отправьте название, **аренду в месяц с НДС** в рублях, площадь **в м²**, адрес, тип помещения, краткое описание, полное описание и особенности.
3. Краткое описание и особенности можно пропустить командой **/skip**. Особенности перечисляйте через запятую.
4. Пришлите от **1 до 10 фотографий** отдельными сообщениями в нужном порядке. После последней отправьте **/done**.
5. После первого фото можно нажать **«Предпросмотр»**: бот пришлёт карточку только вам. Продолжайте загрузку фото или отправьте **/done**.
6. Перед сохранением ещё раз откройте **«Предпросмотр»**, затем нажмите **«Сохранить»**. До сохранения новый объект не виден посетителям.

Пока заполняете карточку, **/cancel** отменяет текущий ввод. Аренда вводится числом без знака ₽; площадь можно написать через запятую, например `82,5`.

## Изменить карточку

Откройте **/admin → 🏠 Список объектов → нужный объект**. В меню карточки можно:

- поменять название, аренду в месяц, площадь, адрес, тип помещения и тексты;
- открыть **«Предпросмотр»** с фотографиями и описанием;
- добавить фотографии или нажать **«Удалить фото N»**: бот сначала покажет это фото, затем попросит подтвердить удаление;
- изменить порядок показа кнопками **«↑ Выше»** и **«↓ Ниже»**;
- **скрыть** объект из каталога и позже снова **показать** его;
- **удалить** объект с подтверждением.

Если объект временно не продаётся, используйте **«Скрыть»**: карточку можно вернуть. Удаление необратимо. Просмотры удалённого объекта сохранятся в отчёте, но он будет назван «(объект удалён)», поэтому перед удалением дождитесь ближайшей сводки, если важно сохранить его название в письме.

Изменения **уже существующей** карточки сохраняются сразу. Если объект открыт посетителям, они увидят правки; для подготовки изменений сначала нажмите **«Скрыть»**, а после проверки — **«Показать»**.

## Проверить, что увидит посетитель

Отправьте **/start** или **/catalog**. В каталоге показаны название, площадь и аренда в месяц. При нажатии на объект бот отправляет фотографии и описание; стрелки открывают соседние объекты, кнопка «Назад» возвращает к каталогу. **«Связаться с менеджером»** открывает чат [@gudd_manager](https://t.me/gudd_manager); посетитель сам отправляет сообщение менеджеру.

## Почтовая сводка

Сводка отправляется **по понедельникам и четвергам в 10:00 по Москве** на адрес, указанный в настройках бота. В письме есть короткая таблица объектов с количеством просмотров и людей. Каждый посетитель показан отдельным компактным блоком: имя, ник, число просмотров, первый и последний просмотр. Ник кликабелен, если он указан в профиле Telegram. В письме не показываются внутренние номера объектов и Telegram ID.

Просмотр фиксируется **при открытии карточки**, а не при одном только запуске бота. Бот сохраняет доступные данные профиля Telegram: ник, имя и фамилию. **Телефон бот автоматически не получает.** Если бот был выключен во время отправки, он попробует отправить пропущенную сводку после запуска.

## Команды

| Команда | Что делает |
| --- | --- |
| **/admin** | Открыть меню управления |
| **/start**, **/catalog** | Посмотреть каталог как посетитель |
| **/cancel** | Отменить текущий ввод в админке |
| **/skip** | Пропустить необязательное поле при добавлении |
| **/done** | Завершить загрузку фотографий |
| **/id** | Показать свой Telegram ID для выдачи доступа |
| **/help** | Показать список доступных команд |

Техническая инструкция по обновлению бота и проверке почты находится в [DEPLOYMENT.md](DEPLOYMENT.md).
