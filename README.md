# GUDD — памятка администратора

Бот [@Gudd_centr_nedvizhimosti_bot](https://t.me/Gudd_centr_nedvizhimosti_bot) показывает посетителям объекты недвижимости. Добавлять и менять карточки можно в личном чате с ботом.

## С чего начать

1. Откройте чат с ботом и отправьте **/admin**.
2. Нажмите **«🏠 Список объектов»**, затем кнопку с названием нужного объекта. Откроется его меню: данные карточки и кнопки для изменений.
3. Нажмите кнопку того, что хотите изменить. Бот пришлёт вопрос, а вы **напишите ответ в строке «Сообщение» внизу чата и отправьте его**, как обычное сообщение человеку. Не нужно редактировать сообщение самого бота.

После выбора поля бот может написать, например: **«Новое значение поля „Описание“: /cancel — отмена»**. Это значит, что бот ждёт от вас новый текст описания. Строка **/cancel — отмена** показывает запасной выход: отправьте команду **/cancel**, только если передумали менять поле. Для продолжения просто напишите новый текст и отправьте его. Команду **/cancel** добавлять к тексту не нужно.

Если бот пишет **«Сохранено»**, изменение уже записано. После этого он снова показывает меню объекта. Чтобы посмотреть карточку с фотографиями, нажмите **«👁 Предпросмотр»**.

Если вместо меню объектов вы видите обычный каталог, отправьте **/admin**. Если бот отвечает **«Нет доступа»**, отправьте **/id** и передайте полученный номер техническому ответственному для добавления в список администраторов.

## Пример: добавить несколько слов в описание

Допустим, описание сейчас заканчивается словами «Есть отдельный вход.», а вы хотите добавить «Рядом парковка.».

1. Откройте **/admin → 🏠 Список объектов → нужный объект**.
2. Найдите его текущее **«Описание»** в сообщении с меню. Скопируйте или подготовьте **весь текст описания** и допишите нужные слова. Например, окончание нового текста будет: **«Есть отдельный вход. Рядом парковка.»**.
3. Нажмите кнопку **«Описание»**. Бот напишет: **«Новое значение поля „Описание“: /cancel — отмена»**.
4. В строку сообщения вставьте **всё обновлённое описание**, а не только добавленные слова. Отправьте сообщение.
5. Дождитесь ответа **«Сохранено»**. Нажмите **«👁 Предпросмотр»** и проверьте результат.

Отправленный текст **полностью заменяет** старое описание. Если отправить только «Рядом парковка.», в карточке останутся только эти слова. Так же заменяются заголовок, адрес, текст кнопки, краткое описание и другие поля. Для полного описания действует ограничение **800 символов**. Если вы нажали «Описание» случайно и ещё ничего не отправили, отправьте **/cancel** — прежний текст сохранится.

**Изменения существующей карточки сохраняются сразу.** Если объект открыт посетителям, они увидят новое описание сразу после сохранения. Чтобы сначала подготовить и проверить правки, в меню объекта нажмите **«Скрыть»**, внесите изменения, откройте **«Предпросмотр»**, затем нажмите **«Показать»**.

## Как менять другие поля

Откройте меню объекта и нажмите кнопку нужного поля. Бот будет ждать **одно новое сообщение**. Отправляйте новое значение целиком:

| Кнопка | Что отправить боту |
| --- | --- |
| **Заголовок** | Короткое название вверху карточки, до 80 символов, например `Офис у метро`. Полный адрес вводится отдельно. Заголовок не меняет текст кнопки в каталоге. |
| **Текст кнопки в каталоге** | Сначала выберите **«Аренда»** или **«Продажа»**, затем отправьте **всю подпись кнопки** одной строкой, до 100 символов. Например: `Москва, ЖК Алхимово · 206,7 м² · 96 млн. ₽`. Бот ничего не добавляет к этому тексту. |
| **Аренда в месяц** | Цену текстом до 50 символов в одну строку, например `71 тыс.`, `71 000` или `по запросу`. Аренда указывается за месяц с НДС. |
| **Цена продажи** | Полную стоимость продажи текстом до 50 символов, например `10,1 млн.`, `от 10 млн.` или `по запросу`. Это отдельная цена; изменение аренды её не меняет. |
| **Площадь** | Число в квадратных метрах, например `82` или `82,5`. |
| **Адрес** | Полный правильный адрес. В карточке он показан отдельной строкой `📍 Адрес`. Текст кнопки в каталоге задаётся отдельно и от изменения адреса не меняется. |
| **Тип помещения** | Например, `Офис` или `Коммерческое помещение`. |
| **Краткое описание** | Полный новый короткий текст. Если он не нужен, отправьте **/skip** — поле очистится. |
| **Описание** | Полный новый текст карточки, до **800 символов**. |
| **Особенности** | Все нужные пункты через запятую, например `Отдельный вход, Парковка`. Чтобы убрать все пункты, отправьте **/skip**. |

После каждого изменения дождитесь сообщения **«Сохранено»**. Если бот сообщает об ошибке в числе или длине текста, исправьте значение и отправьте его ещё раз. Для отмены ввода до сохранения отправьте **/cancel**.

Сокращение цены вы выбираете сами. Например, отправьте `10,1 млн.` — в карточке будет **«10,1 млн. ₽»**; для аренды `71 тыс.` станет **«71 тыс. ₽/мес.»**. Знак ₽ и «/мес.» можно сразу указать в сообщении: бот не добавит их повторно. Текст `по запросу` отображается без этих обозначений. Бот автоматически не округляет цены карточки до миллионов.

**Тексты кнопок аренды и продажи — независимые поля.** Если изменили цену, площадь или адрес карточки, отдельно поправьте подпись кнопки нужного раздела. Иначе на кнопке останется прежний текст. Существующие подписи при обновлении заполнены сокращёнными адресами, площадью и ценой: миллионы обозначены «млн.», тысячи — «тыс.». Это начальное заполнение; дальше подпись редактируете вы.

### Пример: изменить подпись кнопки в продаже

1. Откройте **/admin → 🏠 Список объектов → нужный объект**.
2. Нажмите **«Текст кнопки в каталоге» → «Продажа»**.
3. Отправьте всю новую строку, например: `Москва, ЖК Алхимово · 206,7 м² · 96 млн. ₽`.
4. Дождитесь **«Сохранено»**. Через **/start → «Объекты. Продажа (не пересылать)»** проверьте новую кнопку. Уже отправленный старый список сам не обновится.

Название, площадь, цену или адрес можно вообще не включать в подпись: посетитель увидит именно отправленный текст. Пишите коротко — Telegram может обрезать длинную кнопку, а количество видимых символов зависит от устройства и размера шрифта.

## Добавить новый объект

1. Откройте **/admin → ➕ Добавить объект**.
2. Бот по очереди попросит заголовок, аренду в месяц с НДС, цену продажи, площадь, полный адрес, текст кнопки аренды, текст кнопки продажи, тип помещения, краткое описание, полное описание и особенности. **На каждый вопрос отправляйте отдельное сообщение.** В вопросе указан текущий шаг.
3. Если краткое описание или особенности не нужны, на соответствующем шаге отправьте **/skip**. Особенности перечисляйте через запятую.
4. Когда бот попросит фотографии, отправьте от **1 до 10 фото**, каждое отдельным сообщением. Порядок отправки станет порядком фотографий в карточке. После последнего фото отправьте **/done**.
5. После первого фото можно нажать **«👁 Предпросмотр»**: бот пришлёт черновик только вам. Кнопки **«Аренда»** и **«Продажа»** в предпросмотре позволяют проверить обе цены. Затем можно отправить ещё фото или **/done**.
6. После **/done** проверьте карточку через **«👁 Предпросмотр»** и нажмите **«✅ Сохранить»**. До этого новый объект не виден посетителям. Кнопка **«❌ Отмена»** удаляет незавершённый черновик.

Во время заполнения **/cancel** прекращает создание объекта и возвращает в меню админки. Обе цены вводите текстом, например `71 тыс.` и `10,1 млн.`; площадь — числом, можно через запятую, например `82,5`.

## Фотографии и порядок объектов

В меню объекта нажмите **«🖼 Фото»**. Кнопка **«👁 Вся карточка»** показывает фотографии и описание. Чтобы добавить фото, нажмите **«➕ Добавить фото»**, отправьте фотографии отдельными сообщениями, затем **/done**. В одной карточке может быть не более **10 фотографий**.

Для удаления нажмите **«Удалить фото 1»**, **«Удалить фото 2»** и так далее. Бот сначала покажет выбранную фотографию. Если это нужное фото, нажмите **«Да, удалить»**; если ошиблись, нажмите **«Отмена»**. Номера фотографий зависят от их текущего порядка.

Кнопки **«↑ Выше»** и **«↓ Ниже»** меняют место объекта в общем списке. Кнопка **«← Список»** возвращает к списку объектов.

## Скрыть или удалить объект

Кнопка **«Скрыть»** убирает карточку из каталога посетителей, но сохраняет её и фотографии для администраторов. Кнопка **«Показать»** возвращает карточку в каталог. Это удобно, когда вы готовите изменения.

**«🗑 Удалить объект»** удаляет карточку после отдельного подтверждения. Вернуть её кнопкой уже нельзя. Просмотры удалённого объекта сохранятся в отчёте, но он будет назван «(объект удалён)». Если важно сохранить название в письме, дождитесь ближайшей сводки перед удалением.

## Проверить, что увидит посетитель

Отправьте **/start** или **/catalog**. На первом экране выберите **«Объекты. Аренда (не пересылать)»** или **«Объекты. Продажа (не пересылать)»**. В обоих разделах показаны те же объекты. На каждой кнопке показан текст, заданный администратором отдельно для выбранного раздела. Первоначально это сокращённый адрес, площадь и цена. Внутри карточки показаны **короткий заголовок, полный адрес с 📍, площадь и цена выбранного раздела**.

При нажатии на объект бот отправляет фотографии и описание с ценой выбранного раздела. Стрелки открывают соседние объекты в том же разделе, кнопка **«← К списку объектов»** возвращает к нему. Чтобы поменять раздел, внизу списка нажмите **«← Аренда / продажа»**. **«Связаться с менеджером»** открывает чат [@gudd_manager](https://t.me/gudd_manager); посетитель сам отправляет сообщение менеджеру.

В меню объекта кнопка **«👁 Предпросмотр»** позволяет проверить его без открытия пользовательского каталога. В предпросмотре нажмите **«Аренда»** или **«Продажа»**, чтобы проверить нужную цену. Предпросмотр скрытого объекта или черновика доступен только администратору и не учитывается как просмотр посетителя.

Чтобы снова управлять карточками, отправьте **/admin**.

## Почтовая сводка

Сводка отправляется **по понедельникам и четвергам в 10:00 по Москве** на адрес, указанный в настройках бота. В письме есть общая таблица объектов с количеством просмотров и людей. Ниже для каждого просмотренного объекта показана таблица: одна строка на посетителя с именем, ником, числом просмотров и временем первого и последнего просмотра. Ник кликабелен, если он указан в профиле Telegram. В письме не показываются внутренние номера объектов и Telegram ID.

Просмотр фиксируется **при открытии карточки**, а не при одном только запуске бота. Бот сохраняет доступные данные профиля Telegram: ник, имя и фамилию. **Телефон бот автоматически не получает.** Если бот был выключен во время отправки, он попробует отправить пропущенную сводку после запуска.

## Команды

Команды можно напечатать в строке сообщения и отправить боту.

| Команда | Что делает |
| --- | --- |
| **/admin** | Открыть меню управления; незавершённый ввод сбрасывается |
| **/start**, **/catalog** | Открыть выбор аренды или продажи как посетитель; незавершённый ввод сбрасывается |
| **/cancel** | Отменить текущий ввод в админке и вернуться в её меню |
| **/skip** | Пропустить краткое описание или особенности при добавлении; при редактировании очистить выбранное необязательное поле |
| **/done** | Завершить загрузку фотографий |
| **/id** | Показать свой Telegram ID для выдачи доступа |
| **/help** | Показать список доступных команд |

Техническая инструкция по обновлению бота и проверке почты находится в [DEPLOYMENT.md](DEPLOYMENT.md).
